### Finding (provisional A2-04): "beyond ~1e11 only the objective can be trusted" holds only for the Hilbert objective
- severity: medium; category: doc-claim-false; confidence: reproduced
- claim: README 3 Risk 1 "up to a condition number of about 1e10 the solution is recovered, beyond it only the objective is (defect 9)"; README 4 defect 9 title "Beyond a condition number of about 1e11 only the objective can be trusted".
- observed: F2 `illrandom` (24 random L·D·U equality LPs, x = 1 unique, c = Aᵀ1 + 1, 40 configs): kappa1 1e12-1e14 -> 165 of 167 .optimal answers have the objective off by more than 1e-6 (worst 1.85 relative), kappa > 1e14 -> 244 of 244 (worst 3.43); all carry the ill-conditioning warning. In the Hilbert family c = H·1, so cᵀx = 1ᵀHx is pinned by the rows and the objective is right whatever point is returned.
- why wrong: the general statement tells a user to trust the objective of an ill-conditioned answer; with a generic objective it is as wrong as the point.
- location: README.md:408 (Risk 1), README.md:461-468 (defect 9)
- repro: cd verification/probes/cycle-A && swift build --product F2 -c release && perl -e 'alarm shift; exec @ARGV' 300 .build/release/F2 illrandom | grep BUCKET
- documented: misstated (defect 9 generalises from the Hilbert family).
