## Plan (claims/properties to check)
P1. MILP optimality vs exhaustive enumeration on many small random instances:
    binary; general integer with negative/asymmetric bounds; mixed integer (enumerate integer part, solve
    continuous LP by independent method); equality-constrained; infeasible; unbounded relaxation.
    Configs: both node strategies x deterministic/parallel x presolve on/off.
    Check: status, objective, incumbent feasibility+integrality, bound validity (bound <= opt for min).
P2. Gap semantics: .optimal means incumbent - bound <= max(1e-6, 1e-4*max(1,|inc|)); custom Gap tightens.
    Construct instance where default gap accepts suboptimal incumbent; tight Gap finds true optimum.
P3. Limits: nodeLimit/timeLimit -> .feasible(reason) w/ feasible incumbent + valid bound, or .noSolution;
    never false .optimal/.infeasible. memoryBudgetBytes bounds open nodes as documented.
P4. Determinism: deterministic:true identical run to run; parallel agrees on objective.
P5. MIPLIB 3: ReferenceValues.swift vs published optima (independent knowledge); solve each to them
    with both node strategies (release, generous limits).
P6. Search-tree invariants: monotone node bounds; pruning never discards better solution; incumbent
    updates correct under concurrency.
P7. Adversarial: maximize vs minimize, fixed/free/infinite bounds on integer vars, empty model, no integer
    vars, huge/tiny coefficients, duplicated rows, many optima.
